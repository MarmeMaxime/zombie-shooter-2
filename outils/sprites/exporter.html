Export des sprites en PNG

Les sprites dessinés en code (les générateurs de ce dossier) sont écrits en PNG dans assets/, là où le jeu les charge.

  1. Lancer node outils/exporter_sprites.js (il écrit les fichiers).
  2. Ouvrir cette page depuis le serveur du jeu (http://localhost:8766/outils/sprites/exporter.html).
  3. Cliquer sur « Exporter ».
