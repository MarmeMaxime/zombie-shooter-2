# Ancien

Fichiers que le jeu n'utilise plus, gardés pour mémoire (mêmes chemins qu'avant).

- `assets/son/menu_theme.mp3` : l'ancienne musique du menu, remplacée par une musique générée (`audio.js`).
- `assets/son/background_sound.mp3` : l'ancienne musique du mode normal, remplacée elle aussi par une musique générée.
- `assets/sources/` : les planches de sprites d'origine, d'avant le découpage en images.
- `maquette.txt` : la première maquette des écrans, dépassée.
